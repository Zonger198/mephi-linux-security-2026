# ДЗ №1. Изучение средств защиты ОС GNU/Linux

Бухгалтерский шифр: 372155

В ходе работы был создан пользователь `user1` с UID 1234 и группой `students`.
Для пользователя настроена смена пароля каждые 90 дней.

В `suid-files.out` сохранен результат поиска файлов с установленным SUID-битом.
В `processes.out` сохранен результат поиска процесса с RUID обычного пользователя и EUID 0.

Для проверки SUID была сделана копия утилиты `cat` - `/home/user1/cat-suid`.

Для проверки capabilities была сделана копия `chown` - `/home/user1/chown-cap`,
которой назначена привилегия `cap_chown=ep`.

Для `user1` через sudo разрешено выполнение `/usr/bin/date` от имени root.
Правило находится в `/etc/sudoers.d/user1-time`.

Остальные файлы являются артефактами выполнения задания.
